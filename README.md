## 🛠️ General Setup & Requirements

1. **Python 3.10+** recommended.
2. Each folder contains its own self-contained environment setup (`requirements.txt`, `.env.example`, etc.).
3. To run any day's assignment:
   ```bash
   cd "Day X"
   python -m venv venv
   # On Windows:
   .\venv\Scripts\activate
   # On macOS/Linux:
   source venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env  # Add your API keys if required
   ```
