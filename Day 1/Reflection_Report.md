# Reflection Report - Day 1

**What I Learned:** 
Creating these 20 prompts taught me that an AI's output heavily depends on how constraints and context are framed. Using "Role Prompting" drastically changed the tone of the response, while "Chain-of-Thought" forced the model to give much more logical, structured answers instead of superficial summaries.

**Challenges:** 
The main challenge was formatting the "Few-shot" prompts so the AI understood the pattern without getting confused by the final blank input.
